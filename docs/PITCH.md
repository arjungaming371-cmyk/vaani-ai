# Vaani AI — One-Pager

**One line:** An autonomous AI front-desk that answers every call and WhatsApp message for Indian SMEs — instantly, in Telugu, Hindi, or English — and converts enquiries into booked customers.

**Problem (Themes 2 & 3):** Businesses cannot respond instantly to queries and lose potential customers because enquiries are not followed up efficiently.

**Why now:** LLMs finally speak Indian languages well; self-hosting makes per-conversation cost near zero; official WhatsApp Cloud API makes automated business messaging legitimate and cheap.

**Why us:** We've shipped this pipeline in production-grade form — multilingual voice AI, WhatsApp automation, cross-channel memory, race-safe lead handling — and productized it so ANY business can configure the agent's script without code.

**Moat:** Self-hosted = privacy + zero marginal cost. Multilingual voice = works for the 90% of India that doesn't type English. Cross-channel memory = the agent feels like one receptionist, not two bots.
